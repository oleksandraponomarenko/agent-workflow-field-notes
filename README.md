# Agent Workflow Field Notes

A growing field journal of human–agent workflows and observed agent behavior.

The purpose of this repository is to preserve practical work and observations while their context is still available: what needed to be done, how the human and agent worked together, what each contributed, and what happened at the boundaries of scope, tools, and authorization.

## Reading the records

Each workflow records the task, environment, human and agent responsibilities, execution process, review points, outputs, and results.

The records begin with the author's account. WF-001 and WF-002 now also draw on private operating instructions and a dated execution log; their public summaries omit identifying paths and filenames. WF-003 and WF-004 remain scaffolds. None is a controlled or independently verified case study. The documentation date does not establish when a workflow took place.

Supporting materials will be added as available. Unknown details remain explicitly marked. Reported results, artifact-supported results, and proposed improvements are kept separate.

## Adding or expanding a workflow

Use the [workflow template](templates/workflow-template.md). Expand an existing record when new material concerns that workflow.

Describe actual cooperation, including iterations and limitations. Record a failure or unexpected action in the context of the workflow where it occurred. These records do not establish comparative product performance.

All repository documentation is written in English. Supporting examples should omit private financial details, sensitive local paths, and other information that is unnecessary for understanding the workflow.
